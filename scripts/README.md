# Header and card generators

The animated SVGs in `assets/` are generated by these scripts. Text is drawn with the Anton font (SIL Open Font License) and converted to paths.

```bash
pip install fonttools
curl -L -o Anton-Regular.ttf https://github.com/google/fonts/raw/main/ofl/anton/Anton-Regular.ttf
python scripts/make_header.py Anton-Regular.ttf assets
python scripts/make_extras.py Anton-Regular.ttf assets
```
